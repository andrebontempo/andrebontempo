## 📝 Diretrizes de Edição do README.md

1. **Preservação de Elementos Dinâmicos e APIs:** 
   - O arquivo `README.md` contém integrações importantes (como `readme-typing-svg` para texto animado, `skillicons.dev` para as ícones de tecnologias, e `github-readme-stats` para as estatísticas). 
   - Ao editar o arquivo, **não altere** a estrutura base das URLs dessas APIs a menos que seja explicitamente solicitado.

2. **Estética e Estrutura:**
   - Mantenha o uso de `<div align="center">` para seções puramente visuais (como as de ícones e estatísticas) para garantir simetria no perfil.
   - Mantenha espaçamentos limpos utilizando as quebras de linha ou tags `<br>`.
   - O tom da comunicação no perfil deve ser profissional, direto, amigável e receptivo.

3. **Padrão Visual de Badges:**
   - Ao adicionar novos contatos ou tecnologias através do `img.shields.io`, utilize o estilo `for-the-badge` para manter o padrão visual já estabelecido no projeto.
   - Para os gráficos do GitHub (estatísticas e linguagens), o tema atual utilizado é o `tokyonight`.
